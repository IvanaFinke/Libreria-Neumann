# Libreria Neumann :book:

Página web e-commerce de una librería desarrollada en Blazor Interactive Server y Entity Framework.

### ✨ Funcionalidades
:bust_in_silhouette: Login <br>
:key: Registro <br>
:books: Catalogo <br>
:mag_right: Búsqueda <br>
:inbox_tray: Contacto <br>
:memo: Filtros <br>
:gear: Panel de administrador <br>
:pencil2: CRUD libros (Create, Read, Update, Delete) por unidad o varios mediante un .CSV<br>
:shopping_cart: Carrito <br>
:credit_card: Medios de pago (Transferencia, Efectivo, Tarjeta) <br>
:cop: Encriptación <br>
:smiley_cat: Seccion usuario <br>
:closed_lock_with_key: Olvidaste contraseña <br>

###  :computer: Tecnologías
- .NET <br>
- Blazor <br>
- Entity Framework <br>
- SQL Server <br>
- Bootstrap <br>
- HTML <br>
- CSS <br>
